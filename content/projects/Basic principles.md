## Введение

Со 2 по 4 декабря 2018 года в Мексике проходила итоговая конференция соревнования CASP13, на которой объявляли победителей. На данном соревновании ежегодно конкурировали различные алгоритмы, созданные, в первую очередь, для решения проблемы фолдинга белков. 

В 2018 первое место (и что важно, с огромным отрывом) досталось модели AlphaFold, разработанной командой Google DeepMind.

Сегодня существует уже версия AlphaFold 4, который пресказывает третичную/четвертичную структуру белка по первичной с невероятной точностью. Несмотря на то, что AlphaFold (1) появился еще в 2018, реальным прорывом считается AlphaFold 2 (2020), который достиг точности, сравнимой с экспериментальными методами. О нём речь сегодня и пойдет.

Конкретно в этом блоке я разберу некоторые принципы работы модели AlphaFold 2,  описанные в статье 2021 года  ["Highly accurate protein structure prediction with AlphaFold"  (https://doi.org/10.1038/s41586-021-03819-2)](https://doi.org/10.1038/s41586-021-03819-2 ) без углубления в deep learning (*буду честен, на данный момент я сам понял лишь малую часть*) ¯\\_(ツ)_/¯

Схема 1 - общая структура нейросети AlphaFold. 

Есть одна хорошая фраза:  "учиться нужно не на своих ошибках, а на чужих". Примерно это и делает AlphaFold. 

Главная проблема, которую решает данная нейронная сеть - **фолдинг**. На входе у нас только аминокислотная последовательность (полученная секвенированием), а мы хотим знать как этот белок свернётся в 3D (третичную структуру). 

### Этап 1 - ищем эволюционных родственников:

На вход поступила последовательность: 

> [!NOTE]
> A - F - G - K - L - V - W - E - N

Алгоритм сразу собирает 2 тензора:

1) Парная репрезентация (N<sub>res</sub>, N<sub>res</sub>, C<sub>128</sub>), где N<sub>res</sub> (residues) - количество аминокислотных остатков. 
-    Матрица N * N, где и столбцы, и строки - аминокислоты последовательности. На каждом пересении - степень взаимосвязи аминокислот на основе эволюционных изменений (об этом чуть ниже). 
-    C<sub>128</sub> - массив, который несет информацию о взаимосвязи двух аминокислот на пересечении в данном белке, и "заложен" в каждой ячейке. Формально, каждая ячейка имеет глубину 128, в итоге вы получаете "куб данных" размерностью N * N * 128. 

|     |  A  |  F  |  G  |  K  |               L               |  V  |  W  |  E  |  N  |
| :-: | :-: | :-: | :-: | :-: | :---------------------------: | :-: | :-: | :-: | :-: |
|  A  |     |     |     |     |                               |     |     |     |     |
|  F  |     |     |     |     |                               |     |     |     |     |
|  G  |     |     |     |     |                               |     |     |     |     |
|  K  |     |     |     |     |                               |     |     |     |     |
|  L  |     |     |     |     | 128 чисел в <br>каждой ячейке |     |     |     |     |
|  V  |     |     |     |     |                               |     |     |     |     |
|  W  |     |     |     |     |                               |     |     |     |     |
|  E  |     |     |     |     |                               |     |     |     |     |
|  N  |     |     |     |     |                               |     |     |     |     |

2) Тензор 2 (N<sub>seq</sub>, N<sub>res</sub>, C<sub>256</sub>), где N<sub>seq</sub> (sequences) - количество найденных родственных последовательностей. 
-    Матрица N<sub>seq</sub>* N<sub>res</sub> формируется с помощью **множественного выравнивания последовательностей** (MSA — Multiple Sequence Alignment). Каждая строка в ней - последовательность эволюционно родственного (на основе анализа первичной структуры) белка нашему белку.
-    C<sub>256</sub> - массив, идентичный массиву C<sub>128</sub>, но содержащий информацию о каждой отдельной аминокислоте в белке (заряд, размер, способность участвовать в формировании альфа-спиралей/бета-слоёв). 
-    Получается такой же "куб данных" N<sub>seq</sub>* N<sub>res</sub> * 256
Допустим, мы прошлись по базе данных и нашли несколько родственных последовательностей (на основе определённого % совпадения первичных структур):
> [!NOTE]
>  A - F - G - K - L - V - W - E - N         **- последовательность 1 (наш исходный белок)**
>  A - V - G - R - L - I - W - E - N          **- п. 2**
>  A - K - G - D - L - L - W - K - N       **- п. 3**
>  A - N - G - K - L - I - W - E - N          **-п. 4**

Посмотрите внимательно и найдите коррелляцию. Рассматорим следующие положения:
**Положение 4**: в трёх из четырёх случаев (п.1, п.3, п.4) там стоит положительно заряженная аминокислота (лизин или аргинин). Когда там происходит замена на аспартат (п. 3) , в **положении 8** отрицательно заряженный глутамат меняется на лизин (+).
**Положение 8:** Везде глутамат (-), в случае п.3 лизин (когда (+) на (-) в **положении 4**)
